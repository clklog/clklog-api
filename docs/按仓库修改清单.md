## 1. `clklog-api`

**职责：** 统计查询 API、鉴权校验、报表分页/排序。

| 问题 | 优先级 | 做法摘要 |
|------|--------|----------|
| 硬编码 DB / JWT / Redis | P0 | `application.yml` 改为 `${ENV:默认}`；JWT 与 manage **同默认密钥** |
| Actuator / Druid 匿名公开 | P0 | `SecurityConfig`：仅 `/actuator/health` 放行 |
| CORS `credentials` + `*` | P0 | `ResourcesConfig`：`*` 时关闭 credentials |
| `sortOrder` SQL 注入 | P1 | `SortType.normalizeSortOrder` 仅 asc/desc |
| `limit` 超大分页 | P1 | 新建 `PageLimitUtil`；`ReportServiceImpl` / `AppCrashReportService` 接入 |
| `printStackTrace` | P2 | `DownloadController`、`CalcProcessBoss`、`ExcelExportUtils`、`ClientProfileFile`、`ServletUtils`、`TokenService` 等改 logger |
| ThreadLocal 未 remove | P2 | `ReportServiceImpl.clearThreadLocals` + `ReportThreadLocalCleanupFilter` |
| 趋势 SQL 读编码 | P2 | GB2312 → UTF-8 |

**涉及文件（本轮）：**

- `src/main/resources/application.yml`
- `.../framework/config/SecurityConfig.java`
- `.../framework/config/ResourcesConfig.java`
- `.../api/models/enums/SortType.java`
- `.../api/utils/PageLimitUtil.java`（新）
- `.../api/services/ReportServiceImpl.java`
- `.../api/services/AppCrashReportService.java`
- `.../framework/filter/ReportThreadLocalCleanupFilter.java`（新）
- `.../api/controllers/DownloadController.java`
- `.../api/daemons/CalcProcessBoss.java`
- `.../api/poi/ExcelExportUtils.java`
- `.../api/utils/ClientProfileFile.java`
- `.../common/utils/ServletUtils.java`
- `.../security/service/TokenService.java`

## 2. `clklog-manage`

**职责：** 登录发 Token、项目管理、API Key 管理。

| 问题 | 优先级 | 做法摘要 |
|------|--------|----------|
| 硬编码 DB / JWT / Redis | P0 | 同 api：`${ENV:默认}`；**JWT 必须与 api 一致** |
| Actuator / Druid 匿名公开 | P0 | 同 api，仅 health 公开 |
| CORS `credentials` + `*` | P0 | 同 api |
| API Key 明文打日志 | P1 | 日志改用 `maskApiKey` |
| `maskApiKey` 短 Key 越界 | P1 | 先判长度再截取 |
| ApiKey JSON 序列化空 catch | P2 | `logger.warn`，失败不误报 Cached |
| `printStackTrace` | P2 | `IOUtil`、`ManageServiceImpl`、`ServletUtils`、`TokenService` 等改 logger |
| 部署验证 `buildTag` | 辅助 | `UserInfoDTO` + `AuthServiceImpl.login` + yml `clklog-common.build-tag` |

**涉及文件（本轮）：**

- `src/main/resources/application.yml`
- `.../framework/config/SecurityConfig.java`
- `.../framework/config/ResourcesConfig.java`
- `.../manage/services/ApiKeyService.java`
- `.../manage/services/ManageServiceImpl.java`
- `.../manage/utils/IOUtil.java`
- `.../common/utils/ServletUtils.java`
- `.../security/service/TokenService.java`
- `.../sysmgmt/dto/UserInfoDTO.java`
- `.../sysmgmt/services/AuthServiceImpl.java`

**部署注意：** 与 `clklog-api` 必须成对更新，且 `TOKEN_SECRET`（或默认串）两端相同，否则会大面积 403。

## 3. `clklog-init`

**职责：** 初始化与定时聚合（ClickHouse 等）。

| 问题 | 优先级 | 做法摘要 |
|------|--------|----------|
| `CLKLOG_LOG_DB` 拼进 SQL | P1 | `InitSetting.sanitizeLogDb`：库名仅字母数字下划线 |
| `InOrderCalcProcessBoss` stop NPE | P1 | 成员 `thread` 正确赋值 + 空判断 |
| `printStackTrace` | P2 | `InitProcessBoss`、`IOUtil` 等改 logger |

**涉及文件（本轮，工作区）：**

- `src/main/java/com/zcunsoft/cfg/InitSetting.java`
- `src/main/java/com/zcunsoft/daemons/InOrderCalcProcessBoss.java`
- `src/main/java/com/zcunsoft/daemons/InitProcessBoss.java`
- `src/main/java/com/zcunsoft/util/IOUtil.java`

**说明：** 不改聚合统计口径；日常接口可不更 init；更新只影响当前环境所连库。

## 部署对应关系（简）

| 要验证的修复 | 至少更新的包 |
|--------------|--------------|
| 登录 / JWT / CORS / Actuator / ApiKey / buildTag | **manage**（建议同时 **api**） |

# 日常安全/接口相关（不含 init/receiver）
