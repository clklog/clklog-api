## P2-1 `e.printStackTrace()` 替代日志框架

### 改前要点
```java
} catch (Exception e) {
    e.printStackTrace(); // 标准错误流，不便采集与分级
}
```

### 策略
改为 SLF4J `logger.error` / Lombok `@Slf4j` 的 `log.error`，覆盖 api/manage/init/receiver 等约 16 个文件（含 `DownloadController`、各 `IOUtil` 等）。

### 改后关键代码
```java
} catch (Exception e) {
    logger.error("unexpected error", e);
}
```

```java
// 已有 @Slf4j 的类
log.error("failed to load profiles.", e);
```

## P2-2 ApiKeyService 空 catch（JSON 序列化失败静默）

### 改前要点
```java
} catch (JsonProcessingException e) {
    // 空：失败无日志，且外层仍可能误报 Cached

```

### 策略
打 `warn`；仅序列化并写入 Redis **成功后**再打 Cached debug。

### 改后关键代码
```java
try {
    String info = objectMapper.writeValueAsString(loginUser);
    this.stringRedisTemplate.opsForValue().set(key, info);
    // expire / persist ...
    if (logger.isDebugEnabled()) {
        logger.debug("Cached API Key: {}", maskApiKey(apiKey));
    }
} catch (JsonProcessingException e) {
    logger.warn("Failed to serialize loginUser for API Key cache", e);
}
```

## P2-3 ThreadLocal DateFormat 未 `remove`

### 改前要点
```java
// ReportServiceImpl 多个 ThreadLocal<DateFormat> / DecimalFormat
// 请求结束后未 remove，线程池复用可能导致泄漏
```

### 策略
增加 `clearThreadLocals()`；用 `OncePerRequestFilter` 在 `finally` 中清理。

### 改后关键代码
```java
// ReportServiceImpl
public void clearThreadLocals() {
    yMdFORMAT.remove();
    hFORMAT.remove();
    yMdHmsFORMAT.remove();
    decimalFormat.remove();
}
```

```java
// ReportThreadLocalCleanupFilter
try {
    filterChain.doFilter(request, response);
} finally {
    reportService.clearThreadLocals();
}
```

**文件：**  
`clklog-api/.../ReportServiceImpl.java`  
`clklog-api/.../framework/filter/ReportThreadLocalCleanupFilter.java`

## P2-5 `formatNumber` 恰 1 亿显示异常

### 改前要点
```js
if (number < 100000000) return ... + "万";
if (number > 100000000) return ... + "亿";
// number === 100000000 时两条件都不进，返回 undefined
```

### 策略
`< 1亿` 用万；否则用亿（含正好 1 亿）。

### 改后关键代码
```js
export function formatNumber(number) {
  if (!number && number != 0) return "--";
  else if (number == 0) return 0;
  if (number < 10000) return number.toString();
  if (number < 100000000) return (number / 10000).toFixed(2) + "万";
  return (number / 100000000).toFixed(2) + "亿";
}
```

**文件：** `clklog-ui/src/filters/index.js`  
**影响：** 仅展示文案，不改接口数据。
