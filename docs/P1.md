## P1-1 `sortOrder` 拼进 ORDER BY（SQL 注入）

### 改前要点
```java
// SortType.getSortSqlFormat —— sortOrder 未校验直接拼接
return " order by " + StringUtils.toUnderScoreCase(sortName) + " " + sortOrder;
```

### 策略
白名单：仅 `asc` 合法，其余一律 `desc`。`sortName` 本身仍走原有枚举字段白名单。

### 改后关键代码
```java
private static String getSortSqlFormat(String sortName, String sortOrder) {
    sortOrder = normalizeSortOrder(sortOrder);
    // ... 各字段分支 ...
    return " order by " + StringUtils.toUnderScoreCase(sortName) + " " + sortOrder;
}

private static String normalizeSortOrder(String sortOrder) {
    if (sortOrder != null && "asc".equalsIgnoreCase(sortOrder.trim())) {
        return "asc";
    }
    return "desc";
}
```

**文件：** `clklog-api/.../models/enums/SortType.java`

## P1-2 `limit` 整数拼接无上限

### 改前要点
```java
getListSql += " limit " + (req.getPageNum() - 1) * req.getPageSize()
            + "," + req.getPageSize();
// pageSize 可为超大值，压库
```

### 策略
统一 `PageLimitUtil`：pageSize 默认 10、最大 500；`ReportServiceImpl` 动态分页改用工具类；崩溃分页同步限制。

### 改后关键代码
```java
// PageLimitUtil.java
public static String limitClause(int pageNum, int pageSize) {
    int size = safePageSize(pageSize); // 1..500
    int num = safePageNum(pageNum);
    return " limit " + (num - 1) * size + "," + size;
}
```

```java
// ReportServiceImpl 调用示例
getListSql += PageLimitUtil.limitClause(
    getVisitUriDetailPageRequest.getPageNum(),
    getVisitUriDetailPageRequest.getPageSize());
```

```java
// AppCrashReportService
PageRequest.of(
    PageLimitUtil.safePageNum(pageRequest.getPageNum()) - 1,
    PageLimitUtil.safePageSize(pageRequest.getPageSize()),
    Sort.by(Sort.Direction.DESC, "logTime"));
```

## P1-4 `maskApiKey` 短 Key 越界

### 改前要点
```java
return apiKey.substring(0, 6) + "***" + apiKey.substring(20);
// 长度 < 20 时 StringIndexOutOfBoundsException
```

### 策略
判空、短 Key 直接 `****`；前缀长度与尾 4 位按实际长度计算。

### 改后关键代码
```java
private String maskApiKey(String apiKey) {
    if (apiKey == null || apiKey.isEmpty()) {
        return "";
    }
    if (apiKey.length() <= 10) {
        return "****";
    }
    int prefixLen = Math.min(6, apiKey.length() - 4);
    return apiKey.substring(0, prefixLen)
        + "*******************************"
        + apiKey.substring(apiKey.length() - 4);
}
```

## P1-5 `CLKLOG_LOG_DB` 字符串替换进 SQL

### 改前要点
```java
sql = sql.replace("${CLKLOG_LOG_DB}", setting.getLogDb());
// 库名未校验时可间接注入
```

### 策略
在 `InitSetting` 读写时校验：仅字母数字下划线。

### 改后关键代码
```java
private static String sanitizeLogDb(String logDb) {
    if (logDb == null || logDb.trim().isEmpty()) {
        return "clklog";
    }
    String trimmed = logDb.trim();
    if (!trimmed.matches("^[A-Za-z0-9_]+$")) {
        throw new IllegalArgumentException("invalid init.log-db: " + logDb);
    }
    return trimmed;
}
```

**文件：** `clklog-init/.../InitSetting.java`  
**影响：** 合法库名（如 `clklog`）无感；不改聚合 SQL 业务口径。

## P1-6 `InOrderCalcProcessBoss` stop NPE

### 改前要点
```java
Thread thread = new Thread(...); // 局部变量遮蔽成员
thread.start();
// stop() 里成员 thread 仍为 null → NPE
```

### 策略
赋给成员字段；stop 时空判断。

### 改后关键代码
```java
@PostConstruct
public void start() {
    running = true;
    thread = new Thread(new Runnable() {
        @Override
        public void run() { work(); }
    }, "InOrderCalcProcessBoss");
    thread.start();
}

@PreDestroy
public void stop() {
    running = false;
    if (thread != null) {
        thread.interrupt();
        // join ...
    }
}
```

**文件：** `clklog-init/.../InOrderCalcProcessBoss.java`

## P1-9 登录 `redirect` 开放重定向

### 改前要点
```js
this.redirect = query.redirect; // 未校验，可跳外链
path: this.redirect || "/",
```

### 策略
仅允许站内相对路径。

### 改后关键代码
```js
sanitizeRedirect(redirect) {
  if (!redirect || typeof redirect !== "string") return undefined;
  const value = redirect.trim();
  if (!value.startsWith("/") || value.startsWith("//") || value.includes("://")) {
    return undefined;
  }
  return value;
}
// watch 中：this.redirect = this.sanitizeRedirect(query.redirect);
```

**文件：** `clklog-ui/src/views/login/index.vue`
